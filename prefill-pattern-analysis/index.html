Adoption
Review page component that displays contact information with edit capability. Allows users to verify and update phone, email, and address.

Pros:

  • Consistent UX across forms
  • Built-in validation
  • No custom code needed
  • Automatic VA Profile integration
import ContactInfo from 'platform/forms-system/src/js/components/ContactInfo'; <ContactInfo formContext={formContext} data={formData} page={page} />

prefillTransformer Function

Complex Cases
1,906
Lines of Code
19
Applications
13%
Adoption
Custom transformation functions in each form's config that map data from VA Profile/MVI to the form's data structure. Maximum flexibility for complex scenarios.

Pros:

  • Maximum flexibility
  • Form-specific customization
  • Handles complex data structures

Cons:

  • Requires custom code per form
  • High maintenance burden
  • No code reuse
prefillTransformer: (pages, formData, metadata, state) => { return { pages, formData: { veteranFullName: { first: formData.firstName, last: formData.lastName, }, // Custom transformations... }, metadata }; }

profileContactInfo Pattern

Consider
258
Lines of Code
5
Applications
3%
Adoption
Form definition pattern that provides prefill schemas and UI schemas for contact information fields. Declarative approach with automatic VA Profile integration.

Pros:

  • No custom transformation code
  • Platform-maintained
  • Built-in validation

Cons:

  • Low adoption (only 5 forms)
  • Limited customization
  • Less community support
import { profileContactInfo } from 'platform/forms-system/.../profileContactInfo'; contactInfoPage: { ...profileContactInfo({ required: ['phone', 'email'], label: 'Contact information', }), }

Direct formData Prepopulation

Deprecated
0
Lines of Code
18
Applications
12%
Adoption
Pattern where forms directly set initialData or defaultFormData in the Redux store on form load. No dedicated component, just direct state manipulation.

Why Deprecated:

  • No code reuse
  • Inconsistent implementations
  • Hard to maintain
  • No validation
  • Error-prone
// DO NOT USE - Deprecated pattern const initialData = { veteranFullName: { first: user.profile.firstName, last: user.profile.lastName, }, }; dispatch(setData(initialData));

Decision Matrix: Which Approach to Use?

Scenario Recommended Approach
Contact info on review page (phone, email, address) ContactInfo Component
Personal info on review page (name, DOB, SSN) PersonalInformation Component
Complex custom data transformations needed prefillTransformer Function
Combining multiple data sources prefillTransformer Function
Conditional prefill logic prefillTransformer Function
Simple declarative contact fields profileContactInfo Pattern
Inform users about prefilled data PrefillMessage Component
Direct Redux state manipulation ❌ DO NOT USE (deprecated)
